# Manual-archipelago-for-minesweeper-plus
this is a archipelago manual APworld and Yaml file for Jorel Simpsons Minesweeper+. As of right now I only have a version made for 2.1 however am working on the 3.1.1 implementation.
To use this you should have the Archipelago launcher installed and also go to jorel simpsons Itch page to get it.
Make sure you grab the 2.1 version as that is what the current Apworld is meant for it has been tested to gen and works on Archipelago 0.6.8
install the Apworld in your custom worlds folder or using the laucher use the install custom APworld option the generate your Templates.
check the templates folder in archipelago and if its there your good to go afterwards check the archipelago site for a more detailed explanation on how to Generate a world and how to host just remember to use the Manual client to connect to the host.
If you have any issues they are more than likely my fault due to me still being relatively new to coding if so if im able to i will try to help.
